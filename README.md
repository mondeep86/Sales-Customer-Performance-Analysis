# Sales & Customer Performance Analytics

## Project Overview
This is an end-to-end Data Analytics portfolio project using the Sample Superstore dataset. The project explores sales, profitability, customer behaviour, product performance and regional trends using Python, SQL and Tableau.

## Project Objectives
- Analyse overall sales and profitability.
- Identify high-performing and loss-making products.
- Understand customer and segment performance.
- Compare sales and profit across regions.
- Examine the relationship between discounts and profit.
- Develop actionable business recommendations.

## Dataset
- **Source:** Tableau Sample Superstore dataset
- **Records:** 10,194 rows
- **Columns:** 21
- **Data:** Orders, customers, products, sales, profit, discounts and shipping information.

The dataset is a fictional sample dataset provided for analysis and learning purposes.

## Key Findings
- Technology generated the highest sales and profit among the three main categories.
- Furniture had a relatively low profit margin of 2.61%.
- The West region recorded the highest profit.
- Customer, product and discount performance were analysed to identify business opportunities.
